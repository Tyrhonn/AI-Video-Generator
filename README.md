# AI-Video-Generator

### An Integrated Artificial Intelligence Pipeline for Historical Character Talking-Head Video Generation from Portrait Images and Text for Digital Museums and History Education

Official implementation of our research on an end-to-end AI pipeline for generating talking-head videos of historical figures from portrait images and textual narration.

---

# Introduction 📖

AI-Video-Generator is an end-to-end framework for generating talking-head videos of historical figures from portrait images and textual scripts. The system integrates portrait preprocessing, Vietnamese speech synthesis, facial animation, and holographic video generation into a unified Web platform for digital museums and history education.

# Pipeline

The proposed pipeline consists of five sequential stages:

```text
   Text Input                   Portrait Image
       │                              │
       ▼                              ▼
      TTS                    Background Removal
   (VietNeu)                    (Remove.bg)
       │                              │
       ▼                              ▼
 Speech (.wav)             Foreground Image (.png)
       │                              │
       └──────────────┐┌──────────────┘
                      ▼▼
            Talking Head Generation
                  (SadTalker)
                      │
                      ▼
               Face Enhancement
                   (GFPGAN)
                      │
                      ▼
             HoloFan Ready Video
```

# Getting Started 🏁

## Prerequisites

Before installing the project, make sure the following software is available on your system.

- Python 3.10+
- Node.js 18+
- Git
- FFmpeg

### Install FFmpeg

macOS

```bash
brew install ffmpeg
```

Ubuntu

```bash
sudo apt install ffmpeg
```

Windows

Download FFmpeg and add its `bin` directory to your system `PATH`.

---

## Clone Repository

```bash
git clone https://github.com/Tyrhonn/AI-Video-Generator.git

cd AI-Video-Generator
```

---

## Backend Setup

Navigate to the backend directory.

```bash
cd backend/SadTalker
```

Create and activate a virtual environment.

```bash
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
# venv\Scripts\activate
```

Install Python dependencies.

```bash
pip install --upgrade pip

pip install -r requirements.txt
```

---

## Environment Variables

Copy the example configuration file.

```bash
cp .env.example .env
```

Configure your API keys.

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY

REMOVE_BG_API_KEY=YOUR_REMOVE_BG_API_KEY
```

> **Security Notice**
>
> Never commit your `.env` file to GitHub. Sensitive credentials should remain private.

---

## Run Backend

```bash
python server_api.py
```

After launching successfully:

API Documentation

```
http://127.0.0.1:8000/docs
```

Health Check

```
http://127.0.0.1:8000/api/health
```

---

## Frontend Setup

Open another terminal.

```bash
cd frontend

npm install

npm run dev
```

Then open

```
http://localhost:5173
```
